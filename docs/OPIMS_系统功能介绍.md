# OPIMS 系统功能介绍

## 一、首页看板

### 功能概述

系统启动后的默认页面，提供全局数据概览和一键跳转能力。

### 功能点

**1.1 数字统计卡片**

顶部以卡片形式展示：项目总数、在建数、未开工数、停工数、完工数。数据实时从数据库汇总，切换页面后返回自动刷新。

- 每张卡片显示该状态占全部项目的百分比。
- **点击卡片**可跳转到项目清单，并自动按该状态筛选（点「项目总数」显示全部状态）。
- 数量为 0 的状态整卡淡化显示，不与有数据的卡片抢注意力。

**1.2 世界地图标记**

- 有 GPS 坐标的项目按真实坐标标记（实线圈）。
- **无 GPS 坐标但国别可识别的项目，按国别代表坐标近似定位（虚线圈）**，同一国家多个项目自动散开排布；地图下方标注此类项目的数量。
- 鼠标悬停显示项目简称、状态、国别，以及是否为「按国别近似」定位。
- 不同状态（在建/未开工/停工/完工）用**颜色 + 形状**双重区分（圆点／空心圈／方块／小圆点），因为红绿两色在红绿色盲下无法仅凭颜色分辨。
- 仅当所有项目都既无 GPS、国别也无法识别时，地图区域显示空状态提示。

**1.3 合同额分布（按国别）**

- 以横向条形图展示各国别的合同额合计，按金额降序排列。
- 标题右侧显示合同额总计（亿元）与国别数量。
- 每行显示该国别的合同额（亿元）与项目个数，鼠标悬停高亮。

**1.4 快捷入口**

以卡片形式展示全部 9 个功能板块入口。已实现的板块点击直接跳转；待开发板块点击给出「模块建设中」提示。

### 操作要求

- 数字卡片、地图与合同额数据无需手动刷新，页面加载时自动获取。
- 地图上的「虚线圈」表示按国别近似定位，并非项目实际位置。**如需精确定位**，请在项目清单中为该项目填写 GPS 坐标字段（支持逗号分隔经纬度、度分秒、Plus Code 三种格式）。
- 若某项目国别显示为「其他」而实际有明确国别，说明导入时未能从项目名称/地址中识别出该国。此类项目不会按国别上图，需补填 GPS 坐标，或联系开发方在国别关键词表中补充该国。

## 二、项目清单

### 功能概述

系统核心板块，所有项目的基础数据在此维护，其他板块以「项目简称」为关联键联动。

### 功能点

**2.1 数据导入**

- 导入源：公司项目管理情况汇总表（`.xlsx`，含未开工/在建/停工/完工 4 个 sheet）。
- **仅导入境外项目**，境内项目自动过滤。
- 项目简称和合同编号从同目录的 `海外项目简称.xlsx` 按项目名称自动匹配。
- 不修改原始汇总表。

**2.2 冲突处理**

导入时若同一项目简称已存在，提供三种模式：

| 模式 | 行为 |
|---|---|
| 跳过 | 保留现有数据，跳过冲突项 |
| 覆盖 | 删除旧数据，写入新数据 |
| 保留两者 | 不导入冲突项，返回冲突列表供人工处理 |

**2.3 列表展示与默认筛选**

- 默认仅显示「在建」和「未开工」项目，在建排前。
- 选择任意筛选条件后，取消默认限制，显示全部匹配结果。
- 状态筛选中的「**全部状态**」选项可一次显示所有状态的项目。
- 列表上方显示当前结果的**项目数与合同额合计**；若有生效的筛选条件，以标签形式展示并可一键清除。
- 结果超过每页条数时自动分页（可选 20/50/100/200 条每页）。

**2.4 列表列与排序**

- **合同额**：金额 ≥1 亿时显示为「亿」（如 `9.57 亿`），不足 1 亿显示为「万」（如 `6,620 万`）；数字等宽右对齐便于纵向比对；**默认按合同额从大到小排序**，可点击列头切换。
- **状态**：以「形状 + 颜色 + 文字」三重方式呈现，与地图标记形状一致。
- 国别、状态列均支持点击列头排序。
- 项目简称、实施单位、项目名称过长时截断显示，鼠标悬停显示完整内容。

**2.5 筛选维度**

- 项目类型：EPC / PC / C
- 项目状态：全部状态 / 未开工 / 在建 / 停工 / 完工
- 境内 / 境外
- 国别（下拉值从已有数据自动提取，无需预设字典）
- 关键字：同时搜索项目简称、项目名称、合同编号

**2.6 新建与编辑**

- 点击「新建」按钮打开空表单。
- 点击项目行 →「编辑」打开已有数据表单。
- 可编辑的字段参见需求文档 `待澄清 P0-2`，核心必填字段：项目简称（唯一）、合同编号（唯一）、项目名称。

**2.7 GPS 坐标**

可选字段，支持三种输入格式自动解析：
- 逗号分隔：`25.2048, 55.2708`（纬度, 经度）
- 度分秒：`53°20′22.9″N 6°14′12.1″W`
- Plus Code（开放位置码）

**2.8 项目详情**

点击项目行弹出详情弹窗，按卡片分组展示全部字段：
- 基础信息（含合同文件入口）
- 地点 & 日期
- 状态 & 进度
- 业主 / 设计 / 监理
- 项目经理
- 技术负责人
- 质量 / 安全 / 费控经理

**2.9 合同文件入口**

详情弹窗中「合同编号」旁有 📄 按钮，悬停列出该项目 `01.Contract` 下的合同文件及其分类标签，点击打开。

**2.10 删除**

软删除：项目从列表移除，数据库记录标记为「已删除项目」。其他板块的关联数据保留，不会因删除项目而丢失。

**2.11 导出**

导出当前筛选结果为 `.xlsx` 文件。导出范围 = 当前列表看到的内容。

### 操作要求

- 导入前确保 `海外项目简称.xlsx` 与汇总表在同一文件夹，格式：序号 / 项目简称 / 合同编号 / 项目名称（4列）。
- 项目简称一旦确定，不要随意修改——它关联文件目录名和所有板块数据。
- 导入大批量数据（700+ 项目）时，建议先用「跳过」模式测试，确认无误后再用「覆盖」模式正式导入。

## 三、项目文件

### 功能概述

管理各项目的本地文件，以文件系统为数据源，与项目清单通过项目简称（= 文件夹名）联动。

### 功能点

**3.1 根目录设置**

- 首次使用需设置文件根目录，系统会记住此路径。
- 变更根目录后点击「刷新」，所有文件链接自动指向新路径。

**3.2 目录结构**

根目录下每个项目文件夹名必须与项目简称一致。每个项目文件夹内含 9 个固定子文件夹：

| 序号 | 文件夹 | 用途 |
|---|---|---|
| 1 | 01.Contract | 合同文件 |
| 2 | 02.Sub-contract | 分包合同 |
| 3 | 03.Project Planning | 项目策划 |
| 4 | 04.Quality | 质量管理 |
| 5 | 05.Schedule | 进度管理 |
| 6 | 06.Report | 报告 |
| 7 | 07.Time Sheet | 考勤/工时 |
| 8 | 08.（预留） | 待分配 |
| 9 | 09.Others | 其他文件 |

**3.3 合同文件识别**

系统根据 `01.Contract` 文件夹内文件名自动分类：

| 文件名规则 | 显示标签 | 示例 |
|---|---|---|
| 含 `contract`（不含 `supplement`） | 主合同 | `Main Contract.pdf` |
| 含 `supplement` | 补充合同 | `Supplement Agreement.pdf` |
| 含 `supplement` + 末尾数字 | 补充合同一/二/三… | `Supplement 2.pdf` → 补充合同二 |
| 以上都不含 | 合同文件（兜底） | `agreement.pdf` |

**3.4 文件浏览与操作**

- 树形目录展示，点击文件调用系统默认程序打开/编辑。
- 支持按文件名搜索（文件板块内）。
- 支持内嵌预览 PDF、图片、Office 文档。

**3.5 文件刷新**

- 文件列表在进入页面或点击「刷新」时读取根目录的当前状态，**不做后台实时监控**。
- 在系统外新增/修改/删除文件后，需点击「刷新」或重新进入页面才会看到变化。
- 以文件系统的实际状态为准，不保留历史快照。

### 操作要求

- **文件夹名必须与项目简称完全一致**，否则文件将无法关联到对应项目。
- 合同文件务必放入 `01.Contract`，其他子文件夹不会参与合同识别。
- 合同文件建议命名中包含 `contract` 或 `supplement` 以便系统正确分类。
- 变更根目录路径后，务必点击「刷新」以确保文件列表同步。
- 在系统外增删文件后不会自动反映，需点击「刷新」。

## 四、分包商黑名单

### 功能概述

管理需限制合作的分包商，支持列入、拉出、操作追溯。

### 功能点

**4.1 数据字段**

| 字段 | 必填 | 说明 |
|---|---|---|
| 分包商简称 | ✅ | — |
| 分包商名称 | ✅ | — |
| 国别 | | — |
| 提报项目 | | 关联项目清单中的项目简称 |
| 列入原因 | | — |
| 列入日期 | ✅ | — |
| 限制日期 | | 黑名单有效期截止 |
| 列入提报人 | | — |
| 拉出原因 | | 移出黑名单的原因 |
| 拉出日期 | | 移出日期 |
| 拉出提报人 | | 移出操作的提报人 |

**4.2 数据联动**

- 分包商名称和简称与「项目分包」板块（待开发）的分包商数据关联。
- 提报项目与「项目清单」板块的项目简称匹配。

**4.3 操作规则**

- 新建 → 状态为「列入中」。
- 「列入中」记录可编辑、可删除。
- **拉出操作**：填写拉出原因/拉出日期/拉出提报人并保存后，状态变为「已拉出」。
- **拉出锁定**：已拉出的记录不可再修改、不可删除（保护历史记录完整性）。
- **操作日志**：所有操作（新建、编辑、拉出、删除）均记录到审计日志。

**4.4 筛选**

支持按国别、提报项目、状态（列入中 / 已拉出）筛选。

### 操作要求

- 拉出操作不可逆——填写拉出信息前请确认数据准确。
- 删除仅对「列入中」记录有效，已拉出的记录如需移除请线下操作数据库。

## 七、系统通用功能

### 7.1 数据备份

- 手动触发，选择保存路径。
- 生成文件命名：`opims_backup_YYYYMMDD_HHmm.db`（如 `opims_backup_20260615_1730.db`）。
- 备份文件为 SQLite 数据库完整副本，可独立存储。

### 7.2 数据恢复

- 选择备份文件（`.db`），系统弹框确认「恢复将覆盖现有数据，确认继续？」。
- 确认后数据库被替换，系统自动重连。
- **恢复操作不可撤销**，执行前建议先备份当前数据。

### 7.3 界面语言

- 右上角按钮一键切换中 / 英文。
- 语言选择仅影响当前会话，不持久化。

### 7.4 运行环境

- 系统基于 Windows，单机运行，浏览器的 Web Server 模式。
- 后续计划兼容鸿蒙系统。
- 无需安装任何运行环境，双击 `opims.exe` 即用。
- 同一端口仅允许一个实例运行，重复双击仅打开浏览器不会重复启动。

## 八、性能基线

| 指标 | 上限 |
|---|---|
| 项目总数 | 2000 |
| 单个项目文件夹内文件数 | ~100 |
| 启动扫描 | 不自动全量扫描，按需读取 + 手动刷新 |
| 文件监控 | 不做后台实时监控，进入页面或点「刷新」时读取当前状态 |
