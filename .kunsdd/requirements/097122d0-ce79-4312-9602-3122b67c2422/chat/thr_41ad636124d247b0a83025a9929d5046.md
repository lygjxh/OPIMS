## 后端：新增一个流式接口（同时修 B5）

新增 `GET /api/files/raw?project=&folder=&file=`，返回文件字节（区别于现有 `view` 的"用默认程序打开"）：

```go
func (h *Handler) RawFile(w http.ResponseWriter, r *http.Request) {
    project := r.URL.Query().Get("project")
    folder  := r.URL.Query().Get("folder")
    file    := r.URL.Query().Get("file")
    if project == "" || folder == "" || file == "" {
        http.Error(w, "missing params", http.StatusBadRequest); return
    }

    root := h.root.Get()
    target := filepath.Join(root, project, folder, file)

    // —— B5 边界校验：清理后必须仍在根目录内，挡住 ../ 越权 ——
    absRoot, _ := filepath.Abs(root)
    absTarget, _ := filepath.Abs(target)
    if !strings.HasPrefix(absTarget, absRoot+string(os.PathSeparator)) {
        http.Error(w, "forbidden", http.StatusForbidden); return
    }

    // 只允许内嵌预览的类型，其余一律拒绝（Office 不在此列）
    ext := strings.ToLower(filepath.Ext(file))
    ctype, ok := map[string]string{
        ".pdf": "application/pdf",
        ".png": "image/png", ".jpg": "image/jpeg", ".jpeg": "image/jpeg",
        ".gif": "image/gif", ".svg": "image/svg+xml", ".webp": "image/webp",
    }[ext]
    if !ok {
        http.Error(w, "preview not supported", http.StatusUnsupportedMediaType); return
    }

    w.Header().Set("Content-Type", ctype)
    w.Header().Set("Content-Disposition", "inline")
    http.ServeFile(w, r, absTarget) // ServeFile 自身也会防 .. ，双保险
}
```

`main.go` 注册：`mux.HandleFunc("/api/files/raw", h.RawFile)`（放在 `/api/files/` 之前）。

### 🔴 重点亮点

| 设计决策 | 为什么好 |
|---------|---------|
| **SPI 由系统统一算，项目部不填** | 各项目自行算 SPI 口径不同，横向比较无意义。强制中心统一口径是正确决策 |
| **累计计划产值=0 时 SPI 记无效** | 防止「没填数据 → SPI=0 → 误判红灯」。有 `TestLightWithoutSPI` 守护 |
| **风险灯 = 最严重项 + 判定依据 + 细则要求措施** | 避免「看到灯不知道该做什么」，上下文完整 |
| **归档先复制校验再删原件** | 不用 `os.Rename`，防云盘同步 rename 失败留下半成品 |
| **目标已存在绝不静默覆盖** | 返回 409 + 建议版本号，源/目标文件均不碰 |
| **软删除项目恢复机制** | 同名恢复 + 空值兜底，避免「已存在但看不见」的困惑 |
