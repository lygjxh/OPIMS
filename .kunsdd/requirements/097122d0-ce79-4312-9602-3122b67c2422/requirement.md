# opims - Oversea Project Integrated Management System

## 背景

海外运营中心以阿布扎比分公司为基础，为海外各机构的经营、生产、采购及风险防控提供全寿命周期的指导和支撑。作为公司海外业务的“大脑”和“指挥部”，是公司海外战略落地、市场拓展、项目履约和风险管控的责任主体。

战略统筹能力： 负责研究分析全球政治经济形势、行业发展趋势及区域市场特点，制定并滚动更新公司海外业务发展战略；统筹协调海外各机构业务发展，确保与公司总体战略保持一致。

市场开发能力： 统筹管理海外市场开发活动，建立和维护高层商务关系网络；牵头组织重大海外项目的信息追踪、投标报价及合同谈判；指导、支持各海外机构的属地化市场拓展。

资源整合能力： 整合公司内外、国内国外的优势资源（包括但不限于技术、人才、资金、设备、分包商、供应商等），为海外项目提供高效、优质的资源配置方案。

项目管控能力： 对海外项目执行全过程（从投标策划到竣工交付全寿命周期）进行指导、监督和支持，确保项目在进度、成本、质量、安全等方面满足合同要求和公司标准。

风险防控能力： 建立健全海外业务风险识别、评估、预警和应对机制，重点防控政治风险、法律合规风险、财税风险、汇率风险、安全风险等；指导海外机构制定应急预案并组织演练，保障海外人员、资产和业务安全。

作为海外运营中心项目管理部负责人，负责海外项目全过程的统筹协调与监控；组织项目开工策划、关键节点评审；协调解决项目执行中重大技术和资源问题。因此，我需要建立一套完善的项目信息系统，以便于随时更新、查看各项目的相关信息，并通过数据看板实时掌握项目进度、成本、风险和资源使用情况，为决策提供可视化支持。**该系统的核心建设思路包括：建立标准化的项目信息采集模板，打通海外各机构与总部之间的数据上报通道；构建多维度的数据分析模型，覆盖项目数量、进度、成本、风险、资源、分包、人员等关键管理域；搭建灵活的可视化看板，支撑不同层级管理者的决策需求。**

## 目标

建设一套覆盖海外项目全寿命周期的信息管理系统，实现以下具体目标：

- **信息标准化**：统一项目信息采集模板，确保各海外机构数据上报的规范性和一致性。
- **数据一体化**：打通总部与海外机构的数据通道，实现项目信息的实时汇聚与共享。
- **分析多维化**：构建涵盖进度、成本、风险、资源等多维度的数据分析模型。
- **决策可视化**：搭建灵活的数据看板，为不同层级管理者提供直观的决策支持。

系统暂时包括以下几个功能板块：

1. 首页看板
2. 项目清单
3. 项目进度
4. 项目质量
5. 项目分包
6. 项目人员
7. 分包商黑名单
8. 人员黑名单
9. 项目文件

暂定以上几个板块，后期根据情况再进行优化或增加板块。



## 功能要求

总体要求：

1. 系统基于WINDOWS，后续可能会需要同时支持鸿蒙系统
2. 系统仅需单机运行，可以单机部署 Web Server 通过浏览器访问，要求系统构建的简洁、美观，易于本地操作
3. 整个系统中以项目为基准，各板块数据联动，以项目简称作为关联键
4. 数据导入时，如果存在冲突，则提示冲突，并显示详细信息，并提供冲突处理选项（覆盖/跳过/保留两者）
5. 数据存储在本地 SQLite 数据库，支持手动备份（点击按钮选择保存路径，文件名 `opims_backup_YYYYMMDD_HHmm.db`）及恢复（选择备份文件，弹框确认覆盖后执行）
6. 不需要区分用户权限
7. 界面语言为中英双语可切换

板块要求：

1. 首页看板：
  1. 顶部数字卡片：项目总数 + 按状态（未开工/在建/停工/完工）的分项计数。每张卡片显示占全部项目的百分比；点击卡片跳转项目清单并按该状态筛选；计数为 0 的卡片淡化显示
  2. 世界地图：根据项目位置标记项目点，鼠标悬停显示项目简称、状态、国别；不同状态用**颜色 + 形状**双重区分（见下方"配色与无障碍要求"）。位置数据优先级：GPS 坐标（如果有）&gt; **国别代表坐标**（近似定位，用虚线标记区分，地图下方标注此类项目数量）
  3. 合同额分布（位于地图右侧）：**环形饼图**展示合同额构成
    - 维度切换：**按地区 / 按国别**（默认按地区），地区划分见下方"地区口径"
    - 状态筛选：**全部**（单选，默认）+ **在建 / 未开工 / 完工**（三者可多选）。选中多个状态时取并集
    - 圆心显示当前筛选下的合同额合计（亿元）与项目数
    - 图例显示各分组的名称、金额、占比百分比（不依赖颜色单独传达信息）
    - 按地区时点击扇区或图例可下钻查看该地区的国别明细，下钻沿用当前状态筛选
    - 分组超过 7 个时，尾部合并为"其他 N 项"（不生成新色相，避免色盲下无法区分）
  4. 快捷入口（整行置于页面底部）：9 个功能板块的卡片/按钮。已实现板块点击跳转，待开发板块点击提示"模块建设中"
2. 项目清单：
  1. 基础字段来源于公司项目管理情况汇总表（已解析，见待澄清 P0-2）。系统仅导入境外项目（境内/境外=境外）。
  2. 项目简称和合同编号通过与汇总表同文件夹的 `海外项目简称.xlsx` 映射文件获取（列序：序号/项目简称/合同编号/项目名称），按项目名称匹配。不修改原汇总表格式。
  3. 默认列表仅显示「在建」和「未开工」项目，在建排前；选择筛选条件后不受此限制。状态筛选提供「全部状态」选项一次显示所有项目（对应接口参数 `status=all`）。
  4. 列表展示要求（2026-07 补充）：
    - 合同额 ≥1 亿显示为「亿」（如 `9.57 亿`），不足 1 亿显示为「万」（如 `6,620 万`）；等宽数字右对齐，默认按合同额降序，可点击列头切换
    - 国别、状态列支持列头排序；长文本列截断并悬停显示完整内容
    - 列表上方显示当前结果的项目数与合同额合计；生效的筛选条件以标签展示并可一键清除
    - 结果较多时分页（20/50/100/200 条每页可选）
  5. 额外支持可选字段：GPS 纬度、GPS 经度
  6. 支持导入 Excel（.xlsx），导出为 .xlsx（导出当前筛选结果），支持手动新建、修改、删除等
  7. 点击项目行弹出详情弹窗，分组卡片式显示所有字段（基础信息、地点日期、状态进度、业主/设计/监理、项目经理、技术负责人、质量/安全/费控经理、质量安全）
  8. 支持根据项目类型（EPC/PC/C）、项目状态（未开工/在建/停工/完工）、境内/境外、国别进行筛选，同时支持关键字搜索
  9. 项目简称唯一（与总体要求第3条一致，简称作为系统内关联键），编号也需唯一但仅作为业务标识
  10. 删除项目时，其他板块的关联数据保留并标记为「已删除项目」，不在界面上显示
3. 项目文件：
  1. 有设置根目录按钮，防止本机数据位置变动，可以手动调整整个系统项目文件的根目录
  2. 根目录下各文件夹名与项目清单板块中的项目简称一致，便于自动读取相关数据
  3. 项目文件夹下的文件夹暂定9个，分别为：
    1. 01.Contract
    2. 02.Sub-contract
    3. 03.Project Planning
    4. 04.Quality
    5. 05.Schedule
    6. 06.Report
    7. 07.Time Sheet
    8. 08.（预留）
    9. 09.Others
  4. 系统启动时使用上次保存的根目录路径，不自动全量扫描。提供手动刷新按钮，点击后扫描根目录及其子文件夹的当前文件状态并更新列表。
  5. 启动时不做离线变更检测，以当前文件系统实际状态为准。
  6. **不做后台实时文件监控**（2026-07 变更，原要求为"监控实时文件变动并自动更新"）。变更原因：数据通过华为云盘同步，云盘同步期间会产生大量文件事件；且递归监控云盘大目录会在启动时挂载数千个 watch，拖慢启动并可能触及系统上限。文件变化通过"进入页面 / 点击刷新"感知即可满足使用场景。若将来确需自动刷新，应配合 SSE/WebSocket 向前端推送，并限制监控深度、避免逐文件日志。
4. 项目分包：
  1. 数据来源：月度「在建项目分包商及分包合同管理台账」（Excel），系统支持导入并自动解析；也支持手动新增/编辑/删除单条记录
  2. 列表展示（核心数据来自管理台账的以下字段）：
    - 展示维度：默认按项目维度（可按分包商维度查询）
    - 核心列：项目名称（关联项目清单的项目简称）、分包商名称、分包商层级（见下方"分包商层级"）、分包商主专业（两层分类，见下方"分包商专业分类"）、分包合同编号、合同额（万元）、施工状态（完成百分比）
    - 支持按项目、分包商名称、层级、专业分类、专业进行筛选；支持按合同号、分包商名称关键词搜索
    - 列表上方显示当前筛选结果的分包合同数量、合同金额合计
  3. 点击分包商名称弹出详情卡片，分组展示管理台账中的所有信息：
    - **基础**：分包商名称、实控人、实控人电话
    - **层级与专业**：分包商层级、主专业分类、主专业、合同专业（若与主专业不一致）
    - **合同**：合同编号、合同名称、合同额、补充协议金额、签订日期
    - **施工进度**：进场时间、预计撤场时间、完成百分比、人员数量
    - **人员配置**：现场负责人（含审批版本）、在岗情况；现场技术负责人（含审批版本）、在岗情况；现场安全员（含审批版本）、在岗情况；人员配置是否与合同约定一致；如不一致的情况说明
    - **评价与备注**：是否完成完工履约评价、备注
  4. 支持导入 Excel（.xlsx，格式同管理台账），导出当前筛选结果为 .xlsx
  5. **与黑名单自动关联**：若分包商在分包商黑名单中且状态为「列入中」，则该分包商行显示禁用状态标记（如行背景灰化或加警告图标）；鼠标悬停显示"该分包商已列入黑名单"的提示
5. 分包商库（新增）：
  1. 数据来源：系统内手动新建/编辑；支持批量导入 Excel 模板（见下方"分包商库导入模板"）。模板支持导出，各单位可填写后上传
  2. 列表展示：
    - 基础字段：分包商简称（必填，唯一性）、分包商名称（必填）、注册类型（国内 / 国外 / 当地注册）、主专业分类（采购 / 施工 / 设计 / 咨询，必填）、主专业（二级，必填）、其他专业（多选，可不填）
    - 国别、过往项目数、总合同金额
    - 若为当地注册类型，可关联国内母公司（下拉选择）
    - 支持按注册类型、国别、主专业分类、主专业、母公司进行筛选
    - 支持按分包商名称/简称关键词搜索
  3. 点击分包商卡片进入详情页，展示以下分组：
    - **基本信息**：分包商简称、名称、注册类型、国别、主专业分类、主专业、其他专业、母公司关联（若有）
    - **法定代表人**：名称（必填）、身份证号、联系电话（必填）
    - **联系人**：名称、职务、电话、邮箱
    - **注册信息**（可选）：营业执照号、税号、注册地址、注册资本
    - **合作历史** — 该分包商参与过的所有项目列表（自动聚合项目分包数据 + 手动补充）：
      - 列：项目简称、项目名称、开工日期、完工日期、合同号、合同额、承揽范围、主专业分类、主专业、其他专业、项目状态（在建/完工/停工）
      - 支持按项目状态、年份范围筛选
      - 「导出」按钮：下载该分包商的项目合作清单 Excel
  4. **与黑名单关联**：
    - 若分包商本身在黑名单中，详情页显示"黑名单状态"标签（列入中 / 已拉出）及黑名单记录关键信息
    - 若为国内母公司，且关联的当地公司已进黑名单，显示"关联当地公司已列入黑名单"的提示（列出相关当地公司简称）
6. 分包商黑名单：
  1. 字段列表：分包商简称（必填）、分包商名称（必填）、国别、提报项目（关联项目简称）、列入原因、列入日期（必填）、**限制等级**（待定，后续确认，不同等级行显示不同颜色）、限制日期、列入提报人、拉出原因、拉出日期、拉出提报人
  2. 数据联动：分包商名称和简称与「项目分包」板块的分包商数据自动关联；提报项目与「项目清单」板块的项目简称匹配；当黑名单中的国内母公司标记为"列入中"时，关联的当地注册公司也自动标记为禁用（在项目分包中显示禁用状态）
  3. 操作规则：
    - 支持新建、编辑、删除
    - 所有操作记录到操作日志（谁在什么时间做了什么）
    - 一旦执行「拉出」（填写拉出原因、拉出日期、拉出提报人），该条记录锁定——不可再修改、不可删除
  4. 筛选：支持按国别、提报项目、状态（列入中 / 已拉出）进行筛选
  5. 限制等级变更：不同限制等级（待确认具体级别和定义后补充）在列表中用**不同背景颜色**标示整行
7. 人员黑名单：待后续补充。
8. 其他板块功能待后续补充。

### 配色与无障碍要求（2026-07 新增）

项目状态配色固定为：在建 `#2a78d6`、未开工 `#eda100`、停工 `#d03b3b`、完工 `#0ca30c`。

- 该组合在正常视力下两两可辨（最差色差 ΔE 24.1，达标）
- **红（停工）与绿（完工）在红绿色盲下无法仅凭色相区分**（ΔE 仅 4.1，属视觉生理限制，换色无法解决）
- 因此凡使用状态色处**必须同时提供文字标签或形状**：地图标记用四种形状（圆点/空心圈/方块/小圆点）且悬停显示状态文字；表格状态列带形状与文字；KPI 卡片带图标与文字；图例带文字
- `未开工 #eda100` 在白色背景上对比度仅 2.11（低于 3:1 阈值），**只可用于色块/描边，不可用于文字**
- 修改配色需重新做色盲与对比度校验，不可凭观感选色

合同额饼图的分类配色（按固定顺序取用，不循环复用）：
`#2a78d6` `#eb6834` `#1baf7a` `#eda100` `#e87ba4` `#008300` `#4a3aa7`

- 该色序经色盲与对比度校验通过（最差相邻色差：色盲 ΔE 9.1、正常视力 ΔE 19.6）
- 其中 3 个色对比度低于 3:1，故**图例必须显示名称/金额/占比文字**作为兜底
- 分组超过 7 个时尾部合并为"其他 N 项"，**不得生成新色相**——新增色相在色盲下无法与既有色区分
