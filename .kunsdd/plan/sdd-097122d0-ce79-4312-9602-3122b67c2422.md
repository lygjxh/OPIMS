# OPIMS — 国别档案模块实施计划

## 摘要

新增「国别档案」模块，在 OPIMS 中只读展示 Obsidian 维护的出入境政策台账。用户已在 Obsidian 中维护了 6 个国家/地区的政策笔记（俄罗斯、印度尼西亚、尼日利亚、纳米比亚、越南、阿联酋-阿布扎比），放在 `<根>/08.Policy/出入境政策/` 下。本模块读取这些 Markdown 文件 + YAML frontmatter，通过浏览器展示，不写数据库、不提供编辑功能。

### Step 1: 后端基础结构

#### 1a. 新增 PolicyDir()

**文件**：`backend/services/rootdir.go`

```go
const PolicySubdir = "08.Policy"

func (r *RootDir) PolicyDir() string {
    if r.path == "" {
        return ""
    }
    return filepath.FromSlash(filepath.Join(r.path, PolicySubdir))
}
```

#### 1b. 新增国别别名映射

**文件**：`backend/data/country_alias.go`

```go
package data

// CountryAlias 将 Obsidian 侧文件名/国家名映射为 OPIMS 标准国别。
// key = Obsidian 侧名称，value = OPIMS 标准名（与 backend/services/country.go 一致）。
var CountryAlias = map[string]string{
    "印度尼西亚":    "印尼",
    "阿联酋-阿布扎比": "阿联酋",
}

// NormalizeCountry 尝试别名映射，无匹配则返回原值。
func NormalizeCountry(raw string) string {
    if v, ok := CountryAlias[raw]; ok {
        return v
    }
    return raw
}
```

#### 1c. YAML frontmatter 模型

```go
type PolicyFrontmatter struct {
    Country              string   `yaml:"国家"`
    UpdateDate           string   `yaml:"更新日期"`
    PersonTypes          []string `yaml:"人员类型"`
    VisaType             string   `yaml:"签证类型"`
    Agency               string   `yaml:"办理机构"`
    ProcessMethod        string   `yaml:"办理方式"`
    TimeLimit            string   `yaml:"办理时限"`
    ExpectedDuration     string   `yaml:"预计办理周期"`
    StayValidity         string   `yaml:"停留/有效期限"`
    HealthCert           string   `yaml:"是否需健康证明"`
    NoCriminalRecord     string   `yaml:"是否需无犯罪记录证明"`
    WorkPermitSeparate   string   `yaml:"工作许可是否单独办理"`
    FamilyPolicy         string   `yaml:"家属随行政策"`
    ApproxCost           string   `yaml:"签证大致费用"`
    RiskLevel            string   `yaml:"风险等级"`
    Source               string   `yaml:"信息来源"`
}
```

#### 1d. 解析 RiskLevel

```go
import "regexp"

var riskLevelRE = regexp.MustCompile(`^(高|中|低)`)

// ParseRiskLevel 提取风险等级的前一个字作为颜色分类。
func ParseRiskLevel(raw string) (level string, fullText string) {
    m := riskLevelRE.FindString(raw)
    if m == "" {
        return "未知", raw
    }
    return m, raw
}
```

### Step 2: 后端核心 handler

**文件**：`backend/handlers/policy.go`

#### 2a. GET /api/policy/countries

```
扫描 <PolicyDir>/出入境政策/ 下所有 .md 文件（忽略 . 开头目录和 00/01/02 文件）
对每个文件：
  1. 解析 frontmatter
  2. NormalizeCountry 归一化国名
  3. 查询 /api/projects?country={normalized} 拿项目数（或直接 SQL COUNT）
  4. ParseRiskLevel 提取等级
  5. 检查更新日期是否 > 90 天过期
返回 JSON 数组 [{country, original_name, update_date, risk_level, risk_full_text,
              visa_type, expected_duration, is_outdated, project_count}, ...]
```

**目录不存在时**返回 `{"error": "未找到政策库目录，请确认根目录设置正确，且根目录下存在 08.Policy/出入境政策 文件夹", "code": "POLICY_DIR_MISSING"}` + HTTP 404

#### 2b. GET /api/policy/country/{name}

```
参数 name = 标准国名（如 "印尼"）
扫描文件，找到 normalized name 匹配的那个
返回全部 frontmatter + 正文十章 HTML（用 goldmark 转换）
```

#### 2c. GET /api/policy/internal

```
读取 <PolicyDir>/出入境政策/03 公司内部管理制度摘要.md
返回 Markdown 转 HTML 后的内容
```

#### 路由注册（`main.go`）

```go
mux.HandleFunc("/api/policy/countries", h.PolicyCountries)
mux.HandleFunc("/api/policy/country/", h.PolicyCountry)
mux.HandleFunc("/api/policy/internal", h.PolicyInternal)
```

#### 目录忽略逻辑

```go
func isHiddenDir(name string) bool {

func isAuxFile(name string) bool {
    return name == "00 出入境政策一览.base" ||
```

### Step 3: 前端 — 国别档案列表

**文件**：`frontend/src/views/CountryProfile.vue`

布局：

### Step 6: 样式与无障碍

- 风险等级颜色：`高=#d03b3b / 中=#eda100 / 低=#0ca30c / 未知=#999`
- 每种颜色旁必须附带文字标签（文字本身含义，不依赖颜色）
- `#eda100` 在白色背景对比度 2.11（低于 3:1）**只能用于色块/描边**，不可用于文字
- 过期提醒文字用 `#d03b3b` 红色（文字对比度 ≥ 4.5:1，需验证）
- 沿用 `frontend/src/theme.css` 的设计令牌（spacing, border-radius, font）
